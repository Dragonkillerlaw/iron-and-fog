# 东线：铁与雾 · Iron & Fog

浏览器六角格回合制战棋，以1941年比亚韦斯托克—明斯克方向为战役地图。纯 HTML、CSS、JavaScript，无运行依赖。

[直接游玩](https://dragonkillerlaw.github.io/iron-and-fog/)

## 运行

安装 Node.js 18 或更高版本，在本目录运行：

```sh
npm start
```

打开 http://127.0.0.1:4174 。运行 `npm test` 检查战斗规则。静态托管时直接使用仓库根目录。

## 战役模式

- 完整战役：24回合。德军占领明斯克及三座西部要地中的两座，并击溃至少35%的苏军；苏军阻止其达成目标直到期限。
- 入门关：布列斯特—科布林方向，共14支部队、12回合，德军攻占科布林，苏军防守。两种模式使用独立存档。
- 结算显示胜负原因与双方退场统计；结束后可继续查看地图。

## 操作

- 选择德军、苏军对抗 AI，或上帝视角轮流控制双方。
- 手机：密集部队用编号卡片点选；点绿格预览路线并确认移动。「移动」按钮锁定当前部队，按格精确选目的地。医疗、补给、工程先确认目标。
- 电脑：点击己方部队，再点绿格移动。点击红框敌人预览伤害，确认后攻击。
- 每方每回合各有2次空中侦察和2次战斗支援，选择格子并确认后播放飞机动画。
- 工兵可挖壕、布雷、排雷、架桥。架桥2个己方回合通步兵，3回合通坦克；受攻击或执行其他任务会暂停，点击架桥恢复。
- 医疗队、补给队默认开启自动支援，回合末自动寻找安全范围内友军进行救护、补给或坦克维修；移动、行动或待命后不会再自动支援。可在部队详情单独关闭，选择会被保存。旧存档首次升级时统一开启。
- 火炮射程5格，反坦克炮2格。城市、森林、河流、补给和士气共同影响战斗。
- 下一支未行动、原地待命与回合结束提醒减少漏操作。普通移动在未揭雾、触雷、占城、影响施工时可撤销一次。
- 补给覆盖层显示绿通达、橙断线；火力层显示已发现敌军当前射程。详情提示断补给风险，上回合战况列出被俘、溃散原因。
- AI会集中火力、撤出残部、守卫城市与桥头，并使用航空与工程能力。
- 拖动平移、滚轮缩放；战局保存在当前浏览器。

## 0.5 战斗反馈与进度

- 移动、命中、救护、部队退场、城市易手和架桥均有战场反馈；提示遵守战争迷雾。动画可选标准、快速或关闭，音效默认关闭。
- 部队通过有效攻击、救护、补给与工程行动积累经验。40、100、200经验分别达到熟练、老兵、精锐，攻防加成为4%、8%、12%；基础数值不变。重开战役后经验归零。
- 累计战果显示实际造成伤害、恢复兵力、补给行动、城市夺取和摧毁数量。升级前旧存档从更新后开始累计这些数值。
- 战绩档案保留最近100场已完成战役，区分入门关与完整战役，显示胜方、回合及战果勋章。档案仅保存在本机当前浏览器，不跨设备同步；重复打开同一结算不会重复记入。

## 0.5.2 回合性能

- AI 与回合结算在 Web Worker 中计算，地图拖动与缩放可继续响应；不支持 Worker 时逐支部队执行。
- 仅更新发生变化的部队图形，合并迷雾路径，减少重复绘制。
- 运行 `npm run test:turn-worker` 检查后台与逐步计算的战局、事件及存档一致性。

## 0.6 手机版

- 手机直接进入地图，选择部队后出现救护、补给 / 维修、工兵工程、待命等快捷指令；可收起指令卡。
- 单指拖动、双指缩放；触控缩放后不会误选目标。加减按钮扩大，手机可放大到更近的视野。
- 资料、战报、图例与设置收进菜单弹窗；横屏使用紧凑工具栏，桌面保留原侧栏。
- 运行 `npm run test:map-input` 验证缩放锚点、边界及触控手势；布局按手机尺寸预览检查。

## 文件

`scenario.js` 地形与初始部署；`engine.js` 战斗规则；`app.js` 界面与动画；`assets/` 项目制作的像素立绘图集。

本次独立版本保留234支部队（德军78、苏军156）及扩展城市区域。立绘由本项目已有的 AI 生成素材整理；不依赖商业游戏素材。
